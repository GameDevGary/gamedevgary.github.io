My Dev Journey

As a self-taught developer, my journey started from a simple curiosity about how game worlds were actually constructed. That curiosity quickly turned into a massive rabbit hole of 3D modeling, texturing, and engine workflows.

I spent a long time just learning the quirks of open-source tools like Blender and GIMP, figuring out how to get assets looking right in engines without artifacting. Now, I try to package up what I learn—whether that's a node setup in Blender or an entire project pipeline—so other devs don't have to hit the same roadblocks I did.

  • Awesome-Gamedev Repo

    An absolutely massive, curated list of game development resources spanning every engine, discipline, and tool you can think of.

  • Default Cube

    Hands down one of the best YouTube channels out there for weird, fast, and highly practical Blender node setups.
